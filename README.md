## 🇷🇺 Русский

### ✨ Возможности

- **Поиск комбинаций культур** — автоматический подбор схем с балансом нутриентов `0 / 0 / 0` в каждой зоне поля.
- **Поле 6×6** — визуальное отображение посадок на сетке из 36 ячеек.
- **14 игровых культур** — выбор растений для поиска подходящих комбинаций.
- **Сезонные фильтры** — подбор схем с учётом доступности культур в разные сезоны.
- **Гибкая фильтрация** — отбор по количеству культур и выбранному набору растений.
- **Симметричные схемы** — исключение повторяющихся вариантов с учётом поворотов и отражений.
- **Компактные раскладки** — приоритет аккуратным, симметричным и удобным для использования в игре схемам.
- **Предпросмотр посадок** — игровые иконки растений, количество культур и процент заполненности поля.
- **Редактирование грядки** — загрузка готовых схем и возможность самостоятельно размещать растения.
- **Расчёт нутриентов** — наглядное отображение баланса нутриентов и состава посадок.

## 🇬🇧 English

# 🌱 DST Garden Planner — Планировщик огорода

**An interactive garden planner for Don't Starve Together.** 
### https://indi323.github.io/farmplanner/

A tool for finding optimal crop planting patterns that take into account nutrient balance, seasonality, and visual symmetry.
### ✨ Features

- **Crop combination finder** — automatically generates planting layouts with a `0 / 0 / 0` nutrient balance in each garden quadrant.
- **6×6 garden grid** — visualizes planting layouts across 36 tiles.
- **14 in-game crops** — select crops to find suitable combinations.
- **Seasonal filters** — find layouts based on crop availability in different seasons.
- **Flexible filtering** — filter layouts by crop count and selected crop sets.
- **Symmetrical layouts** — removes duplicate arrangements caused by rotations and reflections.
- **Compact arrangements** — prioritizes neat, symmetrical, and practical layouts for in-game use.
- **Planting previews** — displays in-game crop icons, plant counts, and garden occupancy.
- **Garden editing** — load predefined layouts and manually arrange crops.
- **Nutrient calculator** — clearly displays nutrient balance and garden composition.
